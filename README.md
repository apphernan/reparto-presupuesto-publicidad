# Reparte tu presupuesto publicitario

Web app en español que ayuda a decidir cómo repartir un presupuesto de publicidad online entre plataformas (Google Ads, Facebook, Instagram, WhatsApp Business, YouTube, TikTok, LinkedIn, X, Microsoft Advertising, Pinterest, Amazon Ads, Reddit y Spotify Ads) según el tipo de producto o servicio.

## Cómo usarla

Abre `index.html` con doble clic en cualquier navegador. Necesita conexión a internet porque carga Tailwind CSS, Chart.js y Font Awesome desde CDN.

1. Elige el tipo de producto o servicio (o «Otro» y escríbelo).
2. Introduce tu presupuesto total en euros.
3. Revisa el reparto recomendado y ajústalo: al cambiar un porcentaje, el resto se reajusta en proporción para que el total sea siempre 100 %.

## Datos y fuentes

Los porcentajes parten del reparto real del mercado digital español (IAB Spain y PwC, 2026) y se ajustan con datos de audiencia (DataReportal, IAB Spain Redes Sociales), cuota de buscadores (StatCounter), presupuestos B2B (Dreamdata) y otras fuentes citadas dentro de la app. Salvo los perfiles B2B, son **estimaciones razonadas a partir de datos indirectos**.

## Aviso

Las recomendaciones son orientativas. En ningún caso indican que el presupuesto deba repartirse así de forma obligatoria o definitiva.
